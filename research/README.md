# 研究紀錄：權重與過擬合

## 指標（7 個，皆轉為「滾動 1000 日百分位」後等權平均）
台指權 VIX9D / 1M / 3M / 6M、台指 Cash VIX Oscillator（= VIX3M + VIX6M − VIX9D − VIX1M，方向反向）、前一晚美股 VX30 Roll Yield（反向）、0050 季均線(60MA)乖離率。
台股衍生指標回測時落後 1 日（收盤後資料驅動隔日開盤）；VX30 為前一晚美股。缺值的指標剔除並重新正規化，覆蓋率 < 0.7 不產生訊號。

## 規則
`signal3(b, t1, t2)`：b < t1 → 多方；t1 ≤ b < t2 → 空方（持有避險資產）；b ≥ t2 → 多方（極端恐慌逢低買進，t2 ≥ 1.01 即停用）。

## 過擬合檢定（`r4_search.mjs`）
- 試驗 2520 組：等權、單一指標、逐一剔除、300 組 Dirichlet 隨機權重 × 8 組門檻。
- 勝過 00631L 買進持有（Sharpe 1.10）的試驗僅 3.7%；試驗最大 Sharpe 1.20，中位數 0.85。
- CSCV PBO（S=10）= **40.1%**：樣本內最佳在樣本外落到中位數以下的機率偏高。
- 逐年 Walk-forward（2019–）：每年用過去資料選最佳，Sharpe 1.02，低於買進持有 1.21 與固定等權 θ0.85 的 1.18。

## 結論
權重最佳化沒有穩健的超額效益 → 採**等權**，門檻 0.85（極端區間才避險）。單獨作為輪動規則，2016–2026 並未勝過 00631L 買進持有；較適合作為「風險溫度計」，或搭配 Hybrid／Roll Yield 訊號使用。

## 第二階段：權重方案 × 盤中成交時點（`r5_weights_timing.mjs`，輸出 `r5_out.txt`）
**範圍調整**：網頁只保留「溫度計規則」（≥ t1 轉空方）；Roll Yield／Hybrid／Hybrid II／反向閘門已移除（與 TWN-Stocks-Rotation-Strategy 重複）。Roll Yield 仍是溫度計 7 個指標之一。

**權重方案**
- 等權（預設）。
- 排名加權（walk-forward）：每年初用「過去」資料估各指標預測品質 q＝−corr(風險分位, 標的當日報酬)，由高到低套用美股溫度計的分級權重（0.26／0.18／0.18／0.06／0.036×3）；前 500 個觀測日退回等權。
- 極端加權：每日依各指標「目前歷史分位」距 50% 的距離加權（無需擬合）。

**成交時點（歷史代理）**：A 次日開盤（訊號用前一日資料）、B 次日收盤（同訊號）、C 當日收盤前（訊號用當日資料；以收盤台指權 VIX 代理 13:25 的盤中溫度計）。

**結果（2016-02～2026-11，含成本，買進持有 00631L Sharpe 1.02）**
- 等權 θ0.85：A 0.93／B 1.02／C 1.03。B≈C ⇒ 改善來自「晚一點成交、少吃開盤跳空」，不是資訊更新。θ0.8 時 C 反而較差。
- 排名加權換倉大增（θ0.85 開盤 249 次 vs 117 次），後段（2021 起）Sharpe 0.61 vs 等權 0.78。
- 極端加權僅 θ0.9 + 隔日收盤特別好（Sharpe 1.11），θ0.8 掉到 0.80，屬門檻依賴，不採用。
- 時段報酬：50–80 帶隔夜 +22 bp、日內 −7 bp；80–90 帶兩者皆負；但每日隔夜／日內互換成本遠高於 22 bp，不可行。

**結論**：維持等權。真正的盤中擇時需要歷史盤中台指權資料（MIS 只提供即時報價），需自 2026-11-18 起每日累積多個時段（如 09:15／10:00／11:00／12:00／13:00／13:25）後再研究；目前結果為日資料代理，樣本內外皆無穩定超額，勿過度解讀。
