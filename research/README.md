# 研究紀錄：權重與過擬合

## 指標（7 個，皆轉為「滾動 1000 日百分位」後等權平均）
台指權 VIX9D / 1M / 3M / 6M、台指 Cash VIX Oscillator（= VIX3M + VIX6M − VIX9D − VIX1M，方向反向）、前一晚美股 VX30 Roll Yield（反向）、0050 季均線(60MA)乖離率。
台股衍生指標回測時落後 1 日（收盤後資料驅動隔日開盤）；VX30 為前一晚美股。缺值的指標剔除並重新正規化，覆蓋率 < 0.7 不產生訊號。

## 規則
`signal3(b, t1, t2)`：b < t1 → 多方；t1 ≤ b < t2 → 空方（持有避險資產）；b ≥ t2 → 多方（極端恐慌逢低買進，t2 ≥ 1.01 即停用）。

## 過擬合檢定（`r4_search.mjs`）
- 試驗 2520 組：等權、單一指標、逐一剔除、300 組 Dirichlet 隨機權重 × 8 組門檻。
- 勝過 00631L 買進持有（Sharpe 1.10）的試驗僅 3.7%；試驗最大 Sharpe 1.20，中位數 0.85。
- CSCV PBO（S=10）= **40.1%**：樣本內最佳在樣本外落到中位數以下的機率偏高。
- 逐年 Walk-forward（2019–）：每年用過去資料選最佳，Sharpe 1.02，低於買進持有 1.21 與固定等權 θ0.85 的 1.18。

## 結論
權重最佳化沒有穩健的超額效益 → 採**等權**，門檻 0.85（極端區間才避險）。單獨作為輪動規則，2016–2026 並未勝過 00631L 買進持有；較適合作為「風險溫度計」，或搭配 Hybrid／Roll Yield 訊號使用。
